01 · The research question

What is this project about?

Can patient-specific patterns of inferred cell communication help classify disease, and which LR interactions does a trained GNN rely on? We start with single-cell gene counts, estimate communication between annotated cell types, construct patient graphs, and compare GNNs with appropriate controls.

UC task

Ulcerative colitis versus Healthy comparator using colon single-cell data. This is one IBD subtype, not an all-IBD classifier.

UC v4 LRSignalGNN

MS task

Multiple sclerosis versus IIH clinical controls using CSF cells. IIH controls are not healthy volunteers.

Screened LRDiffusionGNN

Why communication?

A gene list ignores the proposed sender–ligand–receptor–receiver relationship. Graphs retain that structure so its predictive value can be tested.

Biological prior + expression

Opening statement: “My project builds patient-specific ligand–receptor communication graphs from single-cell RNA-sequencing data and evaluates GNNs for two separate disease tasks. I also test whether biological graph structure adds value over simpler models.”

This is a research framework with development results. Clinical diagnostic performance, causal signaling and consistent graph superiority have not been established.

Count matrix

Cell ID, donor ID, cell type, condition, sampling context, study and QC annotations. Disease labels supervise training but are not prediction inputs.

Node features, edge indices, edge scores, LR identity indices and context indices. A picture of the graph is a visualization, not an image-classification input.

What preprocessing happened?

The reviewed pipeline checks original integer counts, source-specific cell quality and doublet evidence, cell annotation and donor/context mapping. In the Cambridge pipeline, retained cells have at least 200 detected genes and at most 20% mitochondrial counts; CellTypist annotation uses its reference model and a probability cutoff of 0.5. These are cell-processing rules, not a patient disease predictor. Other source cohorts retain their documented review protocols rather than being described as one identical raw experiment.

The harmonized MS matrices are restricted to 17,481 shared measured genes before graph normalization. Eligibility also excludes treated MS and comparator diagnoses outside the defined contrast. Such choices need clinical provenance; the program does not create MS labels from gene-expression clustering.

03 · Biological features

Gene expression → ligand–receptor score

Gene expression measures captured RNA associated with a gene in a cell. A ligand is a signaling/interaction molecule associated with the sender; a receptor is associated with the receiver. The LR prior names candidate molecular relationships. Gene expression is not direct evidence that the proteins bound or that a signal was transmitted.

Gene

LGALS1

One named expression variable. Each cell has a measured count for it.

LR pair

LGALS1 → PTPRC

A database-annotated candidate relationship, represented by a ligand name and receptor name.

Directed LR route / channel

T_cells → [LGALS1, PTPRC] → T_cells

Specifies both cell roles and an LR pair. The same pair can occur on different directed routes.

What our scoring code computes

  1. Normalize each cell to counts per 10,000 using the applicable measured-gene universe. Harmonized MS uses the frozen 17,481-gene intersection; UC v4 retains its recorded source-count schemas.
  2. Within each sampling context, retain cell types with at least 20 cells.
  3. Compute each gene’s mean normalized expression and fraction of cells with raw count>0.
  4. Require every subunit of each ligand/receptor complex to meet the 0.1 expression-fraction threshold.
  5. Take the minimum mean across complex subunits, then the geometric mean of sender ligand and receiver receptor values. Store the edge value as log1p(score).
CP10K(c,g) = 10,000 × count(c,g) / Σmeasured genes count(c,g)
L = min(mean sender expression of each ligand subunit)
R = min(mean receiver expression of each receptor subunit)
communication score = √(L × R)
stored LR edge feature = ln(1 + communication score)

Illustrative calculation, not a measured patient: if sender ligand mean=4 and receiver receptor mean=9, the score is √36=6; the stored feature is ln7≈1.946, provided all expression-fraction requirements pass.

Names separated by an underscore can represent complex subunits. For example, the reference target complex ITGA4_ITGB7 needs both components; it is not one gene. A missing measured gene is not replaced silently with a biological zero.

A resource named “consensus” does not certify that every pair has independent binding evidence. The broad prior had4,620 pairs;3,188 meet our conservative role/localization screen, and2,414 are measurable in the screened MS schema. Missing annotation does not prove impossibility. This screen is not experimental validation.

Role definitions and evidence framework: OmniPath intercell documentation. Exact scoring: communication.py.

04 · Representations and dimensions

There are two graph levels

Level A · communication multigraph

Node = cell type in a context. Directed edge = one LR identity and its expression-derived score. Multiple LR edges can connect the same cell-type pair. The individual cells were summarized into cell-type statistics.

Level B · interaction graph used by the current GNN

Vertex = a selected sender/LR/receiver route. Adjacency = shared ligand or receptor components in matching sender/receiver roles. These similarity edges are symmetrized; they do not assert a causal signaling cascade.

Illustrative Level A diagram. Several LR edges between the same two cell types make a multigraph. Autocrine (same-type) routes are allowed. Separate sampling contexts cannot send edges to one another.

The JSON files beside your input

input.json is a metadata object containing file paths, a patient ID and a model-task selector. 05 · How classification works

What is a GNN?

A graph neural network learns a prediction using numerical vertex features and a graph describing which vertices can exchange information. Message passing combines a vertex’s state with related vertices’ states. Training learns the weights that make patient-level outputs useful for the specified classification task.

1 · Counts & metadataCells × genes; patient and context IDs
2 · LR multigraphDirected cell-type communication scores
3 · Select routesTraining-only preprocessing and channel selection
4 · GNN messagesUse interaction similarity and observed-channel masks
5 · Patient scoreLogit → score → saved decision threshold

Exact screened MS architecture

The current screened MS model is a small LRDiffusionGNN, not a large deep GAT. It retains zero-hop (original), one-hop and two-hop route scores. A learned mixture combines them, followed by learned per-channel weights, missingness terms and a bias. The diffusion/readout is mostly linear conditional on the graph and observability.

h₀ = standardized LR scores × presence
h₁ = Aobserved,row-normalized h₀   (isolated vertices retain their own value)
h₂ = Aobserved,row-normalized h₁   (same isolation rule)
h = α₀h₀ + α₁h₁ + α₂h₂, with α = softmax(learned hop weights)
patient logit = Σchannels(learned weight × h + presence weight × presence) + bias
raw score = sigmoid(logit); MS source-only calibration → model score
predicted class = MS if score ≥ saved source threshold, otherwise IIH

Try message passing on a tiny graph

Illustrative chain of three fully observed interaction vertices, with original scores [1,0,3]. Move the slider to see neighborhood aggregation. This teaches diffusion only; it is not a patient prediction.

h₀ = [1.00, 0.00, 3.00]

A = [[0,1,0],[0.5,0,0.5],[0,1,0]]. The actual model learns a mixture of all three hop states; it does not simply choose the last slider position.

UC architecture differs

The selected UC v4 model uses64 interaction vertices with two input features each, a learned 2-dimensional vertex identity, an 8-dimensional hidden projection, two masked message-passing layers, and a flattened patient readout. It is LRSignalGNN. Its raw sigmoid output uses a fixed0.5 threshold; do not apply the MS calibration description to UC.

Targets and supervision

The target is one label per donor: MS=1, IIH=0 or, separately, UC=1, Healthy=0. A vector of 39 MS-task labels has shape(39,); it is distinct from input features. During training, binary classification loss compares predicted logits with source-patient labels, and gradient-based optimization updates learned weights. During prediction, those weights are fixed and the label is not supplied. In the 39-patient three-fold evaluation, each outer model fits 26 source patients and predicts 13 held-out patients.

How training and evaluation stay separate

Known disease labels are used only in the relevant training partitions. The model minimizes a class-balanced binary classification loss with regularization. Inner source folds select settings/epochs; outer patients generate held-out outputs. MS calibration and thresholds are source-only. All contexts of a patient stay together. The older UC model is reported under its recorded v4 protocol, not retroactively under the later MS protocol.

Explain it in 20 seconds: “Each patient becomes a set of LR routes. The GNN exchanges information between related routes, learns which patterns matter, and reduces them to one patient score. I check its predictions on patients excluded from that model’s training and compare against graph controls.”

08 · Doubt clarification

Questions your examiner may ask


26 questions

What is my project in one sentence?

I build patient-specific ligand–receptor communication graphs from single-cell RNA counts and evaluate GNNs for UC-versus-healthy and MS-versus-IIH classification, with held-out explanations and matched controls.

Is my dataset an image, an array or a matrix?

The main expression data are a two-dimensional numerical matrix, stored sparsely. Metadata and LR resources are tables. The model graph is represented by numerical arrays. A heatmap or network picture is a visualization of those arrays; it is not the model input image.

Does a matrix row represent a patient?

In the original count matrix, one row represents a cell. Many cells belong to the same donor. After graph construction and aggregation, the classifier receives one graph/interaction profile per patient and predicts one patient label.

Why do 61,845 cells not mean 61,845 independent training examples?

Those Cambridge cells come from 39 eligible patients. Cells from a patient share biology and sampling. Splitting cells randomly would leak patient information; donor IDs define the independent classification unit.

What do gene-expression counts measure?

They record captured RNA molecules/UMIs associated with gene symbols in individual cells. They are expression measurements, not DNA sequences and not direct measurements of receptor protein abundance or signaling activity. Zero can mean not detected.

What is the difference between a gene and an LR pair?

A gene is one expression variable, such as LGALS1. An LR pair is a prior-annotated relationship between a ligand and a receptor, possibly containing multi-gene complexes. Its score uses expression on the sender and receiver cell types. A selected channel additionally specifies those cell types.

Do you measure physical cell-to-cell contact?

No. Expression-derived LR scores and database priors nominate possible communication. Dissociated scRNA-seq does not establish spatial adjacency, protein binding, receptor activation or causal signaling.

What exactly is a node in this project?

In the patient communication multigraph, a node is an eligible cell type in a sampling context. In the current GNN line-graph view, a vertex is a selected sender-type/LR-pair/receiver-type interaction. These are two different graph levels, and neither is a raw gene-count matrix row.

Is the graph directed?

The underlying LR route is directed from sender to receiver; autocrine routes are allowed. The current interaction-similarity adjacency used for message passing is symmetrized. Directed biological route labels are still preserved on the interaction vertices.

Why are 32 channels not 32 genes?

Each channel is a selected directed cell-type/LR/cell-type triplet. Different channels can share the same ligand or receptor gene. The screened MS model uses 32 such channels, each with a score and an observability flag.

Why use a GNN rather than a normal classifier?

The hypothesis is that biological relationships among LR interactions provide a useful inductive bias. GNNs can exchange information along those relationships. This is a hypothesis to test against no-edge, rewired and simpler models; current results do not establish a consistent benefit.

Which GNN should I demonstrate?

For MS, use the previous screened LRDiffusionGNN, not the unsuccessful multiview experiment. For UC, use the selected v4 LRSignalGNN. The prediction interface selects a checkpoint that excluded each known patient during training.

Does the final MS GNN directly use all 233 gene features stored at every node?

No. The screened diffusion model derives type identities and LR profiles from the patient graph, selects 32 channels and uses their scores/presence. The stored expression panel was used in other experiments; adding it to the later multiview model did not improve performance.

Are UC and MS combined into one classifier?

No. UC uses colon and a Healthy comparator; MS uses CSF and IIH clinical controls. These are separate models with separate labels, schemas and model versions. Cross-disease LR ranking is exploratory comparison, not joint disease diagnosis.

Does UC mean all IBD?

No. Ulcerative colitis is one IBD subtype. The current classification contrast is UC versus Healthy; do not claim that it also diagnoses Crohn disease.

Are IIH controls healthy people?

No. IIH is idiopathic intracranial hypertension, a clinical comparator group. The model distinguishes the sampled MS and IIH cohorts; it is not validated against every other neurological condition.

What does the 0.3085 output mean?

For Cambridge:Sample14, the saved held-out MS model gives an MS-class score about0.3085, below its0.5 threshold, and predicts IIH. This is a research score, not a30.85% clinical chance of MS.

Why can 82.1% accuracy still be weak?

In the multiview LR-only experiment,32/39 predictions were correct but only2/8 IIH controls were recognized. Always predicting MS already gives31/39. Balanced accuracy reflects both class sensitivities and was only0.609 for that model.

What is donor CV versus study holdout?

Donor CV holds out patients while studies can appear on both sides. Study holdout removes an entire study from source training. The latter tests study transfer more directly, but repeated use for model development means it is still not a new untouched final test.

How is leakage reduced?

All contexts of a donor stay together. Fold-specific feature selection, normalization, epochs, calibration and thresholds use source training data under each recorded protocol. Test-patient labels are used to evaluate outputs, not train that patient’s checkpoint.

Can I claim 80.2% accuracy because AUC is0.802?

No. AUC measures ranking over thresholds. The screened MS GNN has AUC 0.802, balanced accuracy0.746 and ordinary accuracy29/39≈74.4%. These are distinct metrics.

Why did the new multiview model fail?

Its held-out scores worsened, and one source fold selected one epoch plus a slope-zero calibrator. That is consistent with unstable selection in a very small cohort. It does not isolate a causal reason, and more epochs alone do not override source-only early stopping.

Can I give a new patient input?

The MS converter accepts scientifically reviewed CSF .h5ad counts with donor, cell-type and sampling-context metadata and the matching measured-gene universe. It does not require a condition label. New IDs use an explicitly unvalidated fold committee; its performance is not the reported donor-CV performance.

What can I honestly claim as the contribution?

An implemented, reproducible LR graph/GNN research pipeline; separate disease evaluations; donor/study validation; graph and non-graph controls; patient explanations; a biological-prior audit; and transparent reporting of successful and unsuccessful experiments.

What remains incomplete scientifically?

Independent validation, a proven advantage of biological graph structure, validated causal signaling and clinical usefulness. Stronger claims require more independent matched patients and biological validation, not just additional cells or another tuned seed.

What are the most important limitations?

Few patients and especially few IIH controls, study-associated differences, different tissues/comparators, uncertain LR annotations, partial cell-type observability, repeated model-development decisions and no prospective clinical validation.

Three claims to get right

  1. Implemented: patient-specific LR graph/GNN classification and model inspection for two separate tasks.
  2. Observed: predictive signal in development, with weak transfer and competitive simpler/graph controls.
  3. Still needed: independent patients, biological validation and evidence of graph advantage before stronger causal or clinical claims.

Closing statement: “The contribution is a transparent LR-GNN research pipeline with patient-level evaluation and explanations. Some development results are promising, but graph superiority and generalization remain open. I report those limits and the unsuccessful experiments rather than selecting only the best-looking score.”

What the project does

Each patient contributes cell-type communication graphs built from single-cell RNA counts and a fixed ligand–receptor prior. The two diseases are separate classification tasks: UC versus healthy colon, and MS versus idiopathic intracranial hypertension (IIH) in CSF. IIH controls are not healthy volunteers; UC does not represent all forms of IBD.

Counts + donor metadata → cell annotation and QC → sender/LR/receiver scores → patient interaction graph → GNN prediction → held-out explanations

The current models retain a line-graph representation: vertices identify a sender cell type, an LR pair and a receiver cell type. Weighted adjacency links interactions with shared ligand or receptor components in matching cell roles. These edges support message passing; they do not assert causal signaling cascades. Earlier patient cell-type GAT experiments remain in the experiment history.
